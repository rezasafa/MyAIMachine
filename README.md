# هم‌صحبت | MyAIMachine

وب‌سایت فارسی ASP.NET Core MVC با C#، SQL Server، Entity Framework Core و ML.NET؛ شامل چت راست‌به‌چپ با طراحی الهام‌گرفته از ChatGPT، تاریخچه گفتگوها، پنل آموزش، تنظیمات و لاگ‌ها.

## روش یادگیری و محدودیت آن

این پروژه **مدل زبانی مولد و معادل ChatGPT نیست**. موتور از صفر و بدون مدل از پیش آموزش‌دیده، از جفت‌های «متن ورودی / پاسخ مطلوب» یاد می‌گیرد:

1. یک نمونه مثل `سلام` → `سلام! خوش آمدید.` اضافه کنید.
2. بازآموزی را اجرا کنید. `FeaturizeText` در ML.NET ویژگی‌های کلمات و نویسه‌ها را از داده‌های شما می‌سازد.
3. هنگام چت، متن یکسان پس از نرمال‌سازی پاسخ دقیق می‌گیرد؛ برای متن جدید، نزدیک‌ترین نمونه بر اساس شباهت کسینوسی انتخاب می‌شود.
4. اگر شباهت از آستانه کمتر باشد، پاسخ جایگزین تنظیم‌شده نمایش داده می‌شود.

حتی **یک نمونه** برای شروع کافی است. پیش از اولین آموزش، دستیار فقط پاسخ جایگزین می‌دهد. مدل جمله‌ای خارج از پاسخ‌های آموزشی تولید نمی‌کند، استدلال ندارد و از پیام‌های قبلی گفتگو برای پیش‌بینی استفاده نمی‌کند. عدد شباهت، احتمال صحت پاسخ نیست. متن بلند را به چند نمونه پرسش/پاسخ تقسیم کنید. برای پاسخ‌گویی واقعاً مولد، باید بعداً یک سرویس مدل زبانی جداگانه اضافه شود.

افزودن/حذف نمونه به‌تنهایی مدل فعال را تغییر نمی‌دهد؛ باید بازآموزی کنید. هر آموزش، مدل را از تمام نمونه‌های فعلی دوباره می‌سازد؛ یادگیری آنلاین یا ادامه وزن‌های قبلی نیست. اگر چند ورودی پس از نرمال‌سازی یکسان باشند، آخرین پاسخ ثبت‌شده استفاده می‌شود. حذف آخرین نمونه، مدل آموزش‌دیده قبلی را پاک نمی‌کند؛ برای بازآموزی حداقل یک نمونه لازم است.

## پیش‌نیازها

- .NET SDK 8 یا SDK سازگار با `net8.0`.
- SQL Server؛ برای توسعه می‌توانید از Docker Compose موجود استفاده کنید.
- دسترسی به NuGet برای بازیابی بسته‌های ML.NET و EF Core.
- نسخه‌های بسته‌ها در فایل پروژه مشخص شده‌اند: EF Core `9.0.2` و ML.NET `4.0.2`؛ ادعای آخرین نسخه ندارند.

## اجرای محلی

دستورها را از ریشه مخزن اجرا کنید.

### ۱. SQL Server

اگر SQL Server موجود دارید، فقط Connection String را تنظیم کنید. برای نمونه Docker:

```bash
cp .env.example .env
# داخل .env یک رمز قوی و اختصاصی برای MSSQL_SA_PASSWORD بنویسید.
docker compose up -d
docker compose logs -f sqlserver
```

منتظر آماده شدن SQL Server بمانید. نسخه Developer فقط برای توسعه/آزمایش است. اطلاعات روی volume ذخیره می‌شوند. پورت دیتابیس فقط روی loopback میزبان منتشر می‌شود.

### ۲. تنظیم اتصال و کلید مدیریت

Linux / macOS (Bash)، در همان ترمینالی که برنامه اجرا می‌شود:

```bash
export ConnectionStrings__DefaultConnection='Server=localhost,1433;Database=MyAIMachine;User Id=sa;Password=YOUR_SQL_PASSWORD;Encrypt=True;TrustServerCertificate=True'
export Administration__ApiKey='YOUR_LONG_RANDOM_ADMIN_KEY'
```

Windows (PowerShell):

```powershell
$env:ConnectionStrings__DefaultConnection = 'Server=localhost,1433;Database=MyAIMachine;User Id=sa;Password=YOUR_SQL_PASSWORD;Encrypt=True;TrustServerCertificate=True'
$env:Administration__ApiKey = 'YOUR_LONG_RANDOM_ADMIN_KEY'
```

رمز را با مقدار تنظیم‌شده در SQL Server جایگزین کنید. برای SQL Server ویندوز با احراز هویت ویندوز، می‌توانید `Integrated Security=True` استفاده کنید. فایل `.env` فقط توسط Docker Compose خوانده می‌شود؛ متغیرهای برنامه را جداگانه تنظیم کنید. هیچ کلید پیش‌فرض فعالی برای مدیریت وجود ندارد.

### ۳. ساخت، ایجاد جداول و اجرا

```bash
dotnet restore MyAIMachine.sln
dotnet build MyAIMachine.sln --no-restore
dotnet run --project src/MyAIMachine -- --migrate
dotnet run --project src/MyAIMachine
```

آدرس محلی: `http://localhost:5080`

دستور `--migrate` مهاجرت‌های EF را اعمال می‌کند و خارج می‌شود؛ اجرای عادی schema را تغییر نمی‌دهد. در صورت ترجیح اجرای دستی، فایل `scripts/schema.sql` اسکریپت idempotent همین migration است؛ آن را داخل دیتابیس `MyAIMachine` اجرا کنید. ایجاد خود دیتابیس در این فایل نیست.

### ۴. اولین آموزش

1. روی «آموزش و تنظیمات مدل» کلیک کنید.
2. کلید `Administration__ApiKey` را وارد کنید و «ورود» را بزنید.
3. متن `سلام` و پاسخ `سلام! خوش آمدید. چطور می‌توانم کمک کنم؟` را ذخیره کنید.
4. «بازآموزی مدل با تمام نمونه‌ها» را بزنید و منتظر پیام موفقیت بمانید.
5. پنجره را ببندید و `سلام` بفرستید.
6. برای پوشش بهتر، نمونه‌های متنوعی مانند `درود` و `سلام خوبی` و سپس پرسش/پاسخ‌های موضوعی اضافه کنید.

کلید مدیریت در localStorage یا تاریخچه چت ذخیره نمی‌شود و با بستن پنجره از ورودی پاک می‌شود.

## ساختار

```text
src/MyAIMachine/
  Controllers/       صفحات MVC و APIهای چت و آموزش
  Models/            موجودیت‌ها و قراردادهای ورودی با اعتبارسنجی
  Data/              DbContext و migration و snapshot
  Services/
    TextModel.cs     نرمال‌سازی فارسی، آموزش ML.NET، ذخیره/بارگذاری و شباهت
    ModelService.cs  مدیریت نسخه مدل و هم‌زمانی آموزش و پیش‌بینی
    BrowserIdentity.cs  شناسه مرورگر با کوکی محافظت‌شده
  Views/Home/        رابط Razor
  wwwroot/           CSS و JavaScript مستقل، بدون وابستگی CDN
scripts/
  schema.sql         اسکریپت مهاجرت SQL Server
  smoke.py           آزمون API روی برنامه و دیتابیس واقعی
tests/MyAIMachine.Tests/  آزمون‌های مستقل موتور و تطبیق migration
```

جدول‌ها: `Conversations`، `ChatMessages`، `TrainingExamples`، `ModelSettings`، `ModelVersions` و `AppLogs`؛ به‌علاوه جدول داخلی تاریخچه migration.

هر `ModelVersion` فایل ZIP مدل و snapshot نمونه‌های همان آموزش را کنار هم نگه می‌دارد. ذخیره نسخه و لاگ آموزش در یک `SaveChanges` انجام می‌شود و مدل فقط پس از موفقیت آن فعال می‌شود. مدل پس از راه‌اندازی مجدد در اولین پیام بارگذاری می‌شود. نسخه‌های قدیمی نگهداری می‌شوند؛ رابط بازگشت به نسخه قبلی در این نسخه وجود ندارد.

گفتگوها به کوکی محافظت‌شده مرورگر متصل‌اند. حذف کوکی یا از دست رفتن کلیدهای ASP.NET Core Data Protection باعث می‌شود همان مرورگر دیگر به تاریخچه قبلی دسترسی نداشته باشد. این شناسه ناشناس است و سامانه حساب کاربری/ورود چنددستگاهی نیست. برای حفظ دسترسی پس از جابه‌جایی سرور یا اجرای کانتینری باید کلیدهای Data Protection را پایدار نگه دارید.

## APIها

| مسیر | کاربرد |
| --- | --- |
| `GET /api/chat` | ۱۰۰ گفتگوی اخیر مرورگر |
| `GET /api/chat/{id}` | پیام‌های یک گفتگو |
| `POST /api/chat` | ارسال `{ conversationId?, message }` |
| `DELETE /api/chat/{id}` | حذف گفتگو و پیام‌هایش |
| `GET /api/training` | وضعیت مدل، تنظیمات و ۲۰۰ نمونه اخیر |
| `POST /api/training/examples` | افزودن `{ input, response }` |
| `DELETE /api/training/examples/{id}` | حذف نمونه از داده‌های آموزش بعدی |
| `POST /api/training/train` | بازآموزی کامل |
| `PUT /api/training/settings` | `{ minimumSimilarity, fallbackResponse }` |
| `GET /api/training/logs` | ۱۰۰ لاگ اخیر |

تمام مسیرهای آموزش نیازمند هدر `X-Admin-Key` هستند. درخواست‌های تغییردهنده داده همچنین نیازمند کوکی antiforgery و هدر `X-CSRF-TOKEN` هستند؛ رابط این کار را انجام می‌دهد. چت فقط به گفتگوهای همان مرورگر دسترسی دارد. متن پیام‌ها با `textContent` نمایش داده می‌شود. لاگ رویدادها متن گفتگو یا کلید مدیریت را کپی نمی‌کند؛ خطاهای کامل در خروجی logger سرور و شناسه خطا در دیتابیس ثبت می‌شود.

## آزمون‌ها

آزمون‌های مدل، بدون نیاز به SQL Server فعال:

```bash
dotnet run --project tests/MyAIMachine.Tests
```

شامل شروع با یک نمونه، متن ناشناخته، نرمال‌سازی فارسی، بازیابی پاسخ مشابه، ذخیره/بارگذاری مدل، پیش‌بینی هم‌زمان و تطبیق snapshot دیتابیس است. این پروژه یک executable آزمون ساده است و با `dotnet run` اجرا می‌شود، نه `dotnet test`.

آزمون سرتاسری روی برنامه در حال اجرا و **دیتابیس آزمایشی جداگانه**:

```bash
MYAIMACHINE_ADMIN_KEY="$Administration__ApiKey" python3 scripts/smoke.py
```

این آزمون داده آموزشی می‌افزاید و مدل مشترک را بازآموزی می‌کند؛ روی دیتابیس واقعی کاربران اجرا نکنید. از سمت دو مرورگر مستقل، آموزش، پاسخ، تاریخچه، جداسازی دسترسی، حذف، اعتبارسنجی و CSRF را بررسی می‌کند.

برای تغییرات بعدی schema:

```bash
dotnet tool restore
dotnet ef migrations add YourChange --project src/MyAIMachine --output-dir Data/Migrations
dotnet run --project src/MyAIMachine -- --migrate
```

## محدوده بهره‌برداری

این نسخه برای توسعه محلی و مجموعه آموزشی کوچک طراحی شده است. آموزش در درخواست HTTP انجام می‌شود؛ برای دیتاست بزرگ باید صف و worker پس‌زمینه اضافه شود. قفل آموزش درون همان پردازش است؛ در استقرار چند نمونه‌ای باید هماهنگی توزیع‌شده اضافه شود. محدودسازی درخواست بر اساس IP و با سقف ۱۲۰ درخواست در دقیقه اعمال می‌شود.

برای انتشار عمومی، HTTPS، مدیریت هویت کاربران/مدیران، نگهداری امن کلیدها، پشتیبان‌گیری و حساب SQL با حداقل دسترسی را متناسب با محیط تنظیم کنید. `TrustServerCertificate=True` نمونه توسعه محلی است. `AllowedHosts` هم به‌صورت پیش‌فرض فقط localhost و 127.0.0.1 را می‌پذیرد.

## وضعیت اعتبارسنجی در محیط تحویل

- MVC، Razor، کنترلرها، سرویس مدیریت مدل و EF Core در پروژه موقت جداگانه با جایگزین موقت موتور ML کامپایل شدند؛ **این جایگزین جزو پروژه تحویلی نیست**.
- migration با مدل EF تطبیق داده شد و اسکریپت SQL از همان migration تولید شد.
- بازیابی بسته `Microsoft.ML` به علت عدم دسترسی شبکه/NuGet ممکن نشد؛ بنابراین **ساخت کامل و آزمون‌های واقعی ML.NET اجرا نشده‌اند**.
- محیط اجازه باز کردن پورت وب و دسترسی به Docker daemon را نمی‌دهد؛ آزمون سرتاسری SQL Server و بررسی مرورگری نیز در این محیط انجام نشد.
