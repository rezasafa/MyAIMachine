# راهنمای آموزش دستیار

از صفحه اصلی، «آموزش و تنظیمات مدل» را باز کنید و کلید مدیریت سرور را وارد کنید. کلید از متغیر محیطی `Administration__ApiKey` خوانده می‌شود؛ آن را قبل از اجرای برنامه تنظیم کنید. اتصال SQL Server نیز باید با `ConnectionStrings__DefaultConnection` تنظیم شده باشد. برای ایجاد جداول، یک بار `dotnet run -- --migrate` و سپس برای اجرا `dotnet run` را در همین پوشه اجرا کنید.

۱. در «وقتی کاربر می‌گوید» پرسش را بنویسید و پاسخ مطلوب را در کادر بعدی وارد کنید.
۲. نمونه را ذخیره کنید؛ می‌توانید نمونه‌های موجود را جست‌وجو، ویرایش یا حذف کنید.
۳. «بازآموزی مدل با تمام نمونه‌ها» را بزنید. پیام وضعیت، تغییرات آموزش‌داده‌نشده را نشان می‌دهد.
۴. در «آزمایش یادگیری» یک پرسش وارد کنید؛ پاسخ مدل فعال و میزان شباهت بدون ثبت در تاریخچه نمایش داده می‌شود.
۵. پنجره را ببندید و گفتگو کنید.

## فایل آموزشی

### نمونه آماده: سلام تا خداحافظی

فایل `samples/greetings.fa.json` در ریشه پروژه، شامل ۴۰ نمونه فارسی برای سلام، احوال‌پرسی، معرفی، تشکر و خداحافظی است.

۱. پنل «آموزش و تنظیمات مدل» را باز کنید و با کلید مدیریت وارد شوید.
۲. در «ورود و خروج اطلاعات»، فایل `samples/greetings.fa.json` را انتخاب کنید و «وارد کردن فایل» را بزنید.
۳. «بازآموزی مدل با تمام نمونه‌ها» را بزنید و منتظر پیام موفقیت بمانید.
۴. در «آزمایش یادگیری» یا چت اصلی، به ترتیب `سلام`، `خوبم ممنون`، `اسمت چیه؟`، `مرسی` و `خدا نگهدار` را امتحان کنید.

مثلاً برای `سلام` پاسخ «سلام! خوش آمدی. حالت چطوره؟» و برای `خدا نگهدار` پاسخ «خدا نگهدار! مراقب خودت باش و باز هم سر بزن.» آموزش داده می‌شود. هر پیام مستقل پاسخ داده می‌شود؛ مدل فعلی ترتیب گفتگو یا پیام‌های قبلی را یاد نمی‌گیرد. برای آموزش عبارت جدید، یک جفت ورودی/پاسخ دیگر اضافه کنید و دوباره بازآموزی کنید.

این فایل فقط نمونه آماده است؛ تا زمانی که آن را وارد و بازآموزی نکنید، مدل فعال تغییر نمی‌کند. اگر قبلاً برای همین عبارت‌ها پاسخ ثبت کرده‌اید، پس از ورود فایل و بازآموزی، پاسخ‌های این نمونه جایگزین آن‌ها می‌شوند.

فایل UTF-8 با پسوند JSON و ساختار زیر را در «ورود و خروج اطلاعات» انتخاب کنید:

```json
[
  { "input": "سلام", "response": "سلام! خوش آمدید." },
  { "input": "ساعت کاری شما چیست؟", "response": "شنبه تا چهارشنبه از ساعت ۹ تا ۱۷." }
]
```

هر بار حداکثر ۵۰۰ نمونه و فایل تا ۹ مگابایت پذیرفته می‌شود؛ پرسش تا ۴۰۰۰ و پاسخ تا ۸۰۰۰ نویسه. فایل نامعتبر بدون ذخیره نمونه‌ها رد می‌شود. ورود فایل، داده‌های قبلی را حذف نمی‌کند. برای پرسش‌های تکراری پس از یکسان‌سازی حروف فارسی، آخرین نمونه ثبت‌شده استفاده می‌شود. بعد از ورود فایل بازآموزی کنید.

«دریافت همه نمونه‌ها» خروجی JSON تمام داده‌های آموزشی را می‌سازد. برای ورود دوباره خروجی بیش از ۵۰۰ نمونه، آن را به چند آرایه JSON کوچک‌تر تقسیم کنید.

## شیوه یادگیری

موتور فعلی پاسخ را از میان نمونه‌های آموزشی انتخاب می‌کند؛ متن تازه تولید نمی‌کند و فایل PDF یا متن آزاد را مستقیم یاد نمی‌گیرد. متن‌های طولانی را به پرسش‌وپاسخ‌های مشخص تبدیل کنید. عدد شباهت احتمال صحت پاسخ نیست. آستانه بالاتر، انتخاب پاسخ مشابه را سخت‌گیرانه‌تر می‌کند.

ویرایش یا حذف نمونه فقط پس از بازآموزی روی پاسخ‌ها اثر می‌گذارد. برای بازآموزی حداقل یک نمونه لازم است؛ حذف تمام نمونه‌ها مدل فعال قبلی را پاک نمی‌کند. اطلاعات آموزشی بین کاربران این سرور مشترک است و مدیریت آن به کلید مدیریت نیاز دارد.
